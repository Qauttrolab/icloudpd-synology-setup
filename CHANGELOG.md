## [1.0.0] — 2026-03-27

### Hinzugefügt
- Initiales Release
- Multi-Account Support via Docker Compose
- `run-all.sh` für automatisierten Tagesbetrieb
- `auth-all.sh` für interaktive 2FA-Authentifizierung aller Accounts
- `docker-shutdown.sh` für sauberes Herunterfahren mit korrekter Reihenfolge
- Vollständige HTML-Anleitung (GitHub Pages)
- README mit Schnellstart-Anleitung
- Compose Vorlage mit Kommentaren
- .env Vorlagen für Root und Account-spezifische Zugangsdaten
